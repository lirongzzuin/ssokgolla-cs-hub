# 01. ALF 지식

ALF가 답변 근거로 쓰는 문서 목록과 등록 방법이다.
원문은 `docs/knowledge-source/`에 있고, 채널톡에는 정제본(`dist/knowledge/`)만 올린다.

## 원칙

| 원칙 | 이유 |
|---|---|
| **주문별 사실(상태·송장·출고일)은 지식에 넣지 않는다** | 주문마다 다르고 매일 바뀐다. 주문 사실은 태스크(허브 API)로만 확인한다 |
| **판매채널별로 문서를 나눈다** | 반품 신청 위치·용어가 다르다. 한 문서에 섞으면 ALF가 쿠팡 고객에게 네이버페이 메뉴를 안내한다 |
| **위탁판매 내부 사정은 지식에 넣지 않는다** | 지식 문장은 그대로 고객에게 나간다. 빌드가 금지어(공급처·도매·매입·원가·위탁·발주)를 검사한다 |
| **값(배송비·출고일)은 `values.json` 한 곳에서 관리** | 바뀌면 값만 고치고 다시 빌드·업로드한다 |

## 등록할 문서

`npm run build-knowledge` 결과(`dist/knowledge/`):

| 파일 | 채널톡 지식 폴더 | 내용 | 원문 |
|---|---|---|---|
| `common__order-and-shipping-faq.md` | 공통 | 출고·도착·배송비·분리배송·상담 시간 | `knowledge-source/common/` |
| `smartstore__shipping.md` | 네이버 스마트스토어 | 취소·배송지 변경·배송 조회(네이버페이 주문내역) | `knowledge-source/smartstore/` |
| `smartstore__exchange-return.md` | 네이버 스마트스토어 | 반품 신청·기간·배송비·교환·환불 | 〃 |
| `coupang__shipping.md` | 쿠팡 | 취소·배송지 변경·배송 조회(마이쿠팡) | `knowledge-source/coupang/` |
| `coupang__exchange-return.md` | 쿠팡 | 반품 신청·기간·배송비·교환·환불 | 〃 |


## 등록 절차

1. `docs/knowledge-source/values.json`에는 데모 상점용 값이 들어 있다(시연용, 실제 운영 값 아님). 바꿀 때만 고친다.
2. `npm run build-knowledge` → 모든 줄이 ✓ 인지 확인(✗면 빈 값·금지어를 고친다).
3. 채널톡 ALF 지식에 위 폴더 구조대로 업로드한다.
4. `docs/test-scenarios.md`의 A(단순 FAQ) 문항으로 답변을 확인한다.
