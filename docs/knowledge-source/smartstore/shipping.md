# 배송·주문 변경 안내 — 네이버 스마트스토어 주문

이 안내는 **네이버 스마트스토어에서 주문하신 경우**에만 해당합니다.

## 주문 취소
- 상품 준비가 시작되기 전에는 네이버페이 주문내역에서 직접 취소하실 수 있고, 바로 처리됩니다.
- 상품 준비가 시작된 뒤에는 바로 취소되지 않을 수 있어 담당자가 확인 후 안내드립니다.
- 이미 출고된 주문은 취소 대신 상품을 받으신 뒤 반품으로 진행됩니다.

<!-- 내부 -->
"상품 준비 시작" = 공급처 발주 완료. 발주 후 취소는 공급처 출고 중지가 필요해서 사람이 처리한다(ALF 태스크가 ESCALATE).
<!-- /내부 -->

## 배송지 변경
- 상품 준비가 시작되기 전에는 네이버페이 주문내역에서 배송지를 직접 바꾸실 수 있습니다.
- 그 뒤에는 담당자가 변경 가능 여부를 확인 후 안내드립니다. 출고된 뒤에는 변경할 수 없습니다.
- 상담 중에 새 주소를 채팅으로 남기지 않으셔도 됩니다.

## 배송 조회
출고되면 네이버페이 주문내역의 배송 조회에서 송장번호와 배송 상태를 확인하실 수 있습니다.
