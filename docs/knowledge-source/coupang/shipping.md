# 배송·주문 변경 안내 — 쿠팡 주문

이 안내는 **쿠팡에서 주문하신 경우**에만 해당합니다. 이 상품은 판매자가 직접 배송하는 상품입니다.

## 주문 취소
- 상품 준비가 시작되기 전에는 쿠팡 마이쿠팡 > 주문목록에서 직접 취소하실 수 있습니다.
- 상품 준비가 시작된 뒤에는 바로 취소되지 않을 수 있어 담당자가 확인 후 안내드립니다.
- 이미 출고된 주문은 취소 대신 상품을 받으신 뒤 반품으로 진행됩니다.

<!-- 내부 -->
판매자가 쿠팡 API로 주문을 취소하면 판매자 점수(주문이행)가 떨어진다. 고객이 직접 취소하도록 안내하는 이유다.
<!-- /내부 -->

## 배송지 변경
- 상품 준비가 시작되기 전에는 마이쿠팡 > 주문목록에서 배송지 변경이 가능한지 확인해 주세요.
- 그 뒤에는 담당자가 변경 가능 여부를 확인 후 안내드립니다. 출고된 뒤에는 변경할 수 없습니다.

## 배송 조회
출고되면 마이쿠팡 > 주문목록의 배송 조회에서 송장번호와 배송 상태를 확인하실 수 있습니다.
