# 지식 원문 (knowledge-source)

채널톡 ALF 지식에 올릴 정책 문서의 **원문**이다. ALF에는 이 파일을 그대로 올리지 않고
`npm run build-knowledge`로 정제한 `dist/knowledge/*.md`를 올린다(업로드 목록: `docs/channeltalk/01-knowledge.md`).

## 작성 규칙

| 규칙 | 이유 |
|---|---|
| 판매채널별로 파일을 나눈다(`smartstore/`, `coupang/`, 공통은 `common/`) | 반품 신청 위치·용어가 채널마다 달라 ALF가 섞어 답하면 안 된다 |
| 운영자용 메모는 `<!-- 내부 -->` … `<!-- /내부 -->` 사이에 쓴다 | 위탁판매 사정(공급처, 발주 시점)은 직원에게 필요하지만 고객에게 노출되면 안 된다. 빌드 때 지운다 |
| 가게마다 다른 값은 `{{키}}`로 쓰고 `values.json`에 채운다 | 배송비·출고일이 바뀌어도 원문을 고치지 않는다. 값이 비어 있으면 빌드가 실패한다 |
| 도착 예정일을 약속하는 문장을 쓰지 않는다 | 출고 후 배송은 택배사 사정이다. "출고 후 보통 1~2일"처럼 통계로만 쓴다 |
| 법 조항은 고객이 이해할 말로 풀어 쓴다 | 지식은 ALF가 고객에게 그대로 옮길 수 있는 문장이어야 한다 |

빌드는 아래를 검사하고 하나라도 걸리면 실패한다.
- 채워지지 않은 `{{키}}`
- 정제 결과에 남은 금지어: `공급처`, `도매`, `매입`, `원가`, `위탁`, `발주`
